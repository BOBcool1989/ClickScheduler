# ClickScheduler

定时点击调度工具，支持可视化配置鼠标点击任务，可设置定时执行、循环执行。

## 功能特性

- 🖱️ **可视化任务配置** — 图形化界面添加/编辑/删除点击任务
- ⏰ **灵活定时** — 支持定时执行、循环执行（每天/每周/间隔分钟）
- 📍 **坐标点击** — 支持绝对坐标点击和相对窗口坐标点击
- 🔁 **循环模式** — 支持按次数循环或无限循环
- 💾 **配置保存** — 任务配置自动保存到 JSON 文件
- 🚀 **独立 exe** — 打包为单文件 exe，无需 Python 环境

## 使用方法

### 方式一：直接运行 exe（推荐）

1. 下载 `dist/ClickScheduler.exe`
2. 双击运行（无需安装 Python）
3. 添加任务后点击「启动调度」

### 方式二：运行 Python 脚本

```bash
pip install pyautogui tkinter
python main.py
```

## 添加任务

1. 点击「新增任务」
2. 填写任务名称
3. 选择触发方式：
   - **定时执行** — 在指定时间执行一次
   - **循环执行** — 按间隔分钟数循环执行
   - **每日执行** — 每天指定时间执行
   - **每周执行** — 每周指定星期和时间执行
4. 设置点击坐标（可点击「拾取坐标」后移动鼠标到目标位置按快捷键）
5. 选择点击类型和次数
6. 点击「保存任务」
7. 主界面勾选任务并点击「启动调度」

## 坐标拾取

- 点击「拾取坐标」按钮
- 将鼠标移动到目标位置
- 按下 `F9` 键（默认快捷键）
- 坐标自动填入 X/Y 输入框

## 配置文件

任务保存在 `tasks.json`，格式示例：

```json
[
  {
    "name": "任务1",
    "trigger_type": "scheduled",
    "trigger_time": "10:00",
    "click_x": 100,
    "click_y": 200,
    "click_type": "left",
    "click_count": 1,
    "loop_count": 1,
    "enabled": true
  }
]
```

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ClickScheduler main.py
```

生成的 exe 在 `dist/ClickScheduler.exe`

## 技术栈

- Python 3.x
- tkinter — GUI
- pyautogui — 鼠标点击模拟
- threading — 后台调度线程

## 注意事项

- 坐标基于屏幕绝对位置
- 运行时请勿移动鼠标到非目标区域
- 部分程序（如管理员权限窗口）可能需要本程序也以管理员身份运行
- 建议先测试坐标是否正确

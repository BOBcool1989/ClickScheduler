# ClickScheduler - 定时点击工具

## 功能说明

定时点击工具，支持：
- 坐标模式：在指定屏幕坐标处自动点击
- UIA模式：识别窗口内元素并自动点击
- 时间范围控制（默认9:00-17:00）
- 开机自启动
- 系统托盘静默运行

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

双击 `启动.bat` 或在命令行运行：
```bash
python main.py
```

## 使用说明

### 基本设置 Tab
- **时间范围**：设置点击生效的时间段
- **点击类型**：左键单击/双击、右键单击、拖拽
- **执行频率**：设置点击间隔（秒/分钟/小时）
- **点击次数**：设置最大点击次数（0=无限）
- **启用/暂停**：启动或暂停点击引擎

### 坐标模式 Tab
- 点击「添加坐标 (抓取)」：全屏半透明显示，移动鼠标查看坐标，左键点击获取坐标
- 点击「添加坐标 (手动输入)」：手动输入X/Y坐标
- 支持添加多个坐标点，按顺序点击

### UIA模式 Tab
- 点击「刷新窗口列表」：获取当前所有窗口
- 选择目标窗口后点击「识别元素」：列出窗口内所有可点击元素
- 选择元素后点击「使用选中元素」：设置为点击目标

### 设置 Tab
- **开机自启**：设置开机时自动启动
- **托盘设置**：关闭按钮最小化到托盘（不退出程序）

## 系统托盘

程序启动后会在系统托盘（右下角）显示图标：
- 左键点击：显示/隐藏主窗口
- 右键菜单：显示主窗口、启用/暂停、退出

## 开机自启

勾选「开机自启」后，程序会自动添加到注册表，下次开机时自动启动（最小化到托盘）。

## 配置文件

配置保存在：`%APPDATA%\ClickScheduler\config.json`

可手动编辑或删除该文件重置配置。

## 注意事项

1. UIA模式需要安装 pywinauto：`pip install pywinauto`
2. 坐标抓取时，右键或ESC键取消
3. 程序需要保持运行才能执行定时点击
4. 开机自启需要程序已经被打包成exe或脚本路径固定

## 打包成exe（可选）

使用 PyInstaller 打包成独立exe文件：

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name ClickScheduler main.py
```

打包后在 `dist/` 目录生成 `ClickScheduler.exe`。

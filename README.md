# ClickScheduler

定时点击调度工具，支持可视化配置鼠标点击任务，可设置定时执行、循环执行。

## 功能特性

- 🖱️ **可视化任务配置** — 图形化界面添加/编辑/删除点击任务
- ⏰ **灵活定时** — 支持定时执行、循环执行（每天/每周/间隔分钟）
- 📍 **坐标点击** — 支持绝对坐标点击
- 🔁 **循环模式** — 支持按次数循环或无限循环
- 💾 **配置保存** — 任务配置自动保存到 JSON 文件
- 🚀 **独立 exe** — 打包为单文件 exe，无需 Python 环境

## 使用方法

### 方式一：直接运行 exe（推荐）

1. 下载 [ClickScheduler.exe](https://github.com/BOBcool1989/ClickScheduler/releases/latest)
2. 双击运行（无需安装 Python）
3. 在「坐标模式」Tab 添加点击坐标
4. 在「基本设置」Tab 设置时间和间隔
5. 点击「启用」开始调度

### 方式二：运行 Python 脚本

```bash
pip install pyautogui pystray Pillow
python main.py
```

## 添加坐标

1. 切换到「坐标模式」Tab
2. 点击「添加坐标 (抓取)」
3. 屏幕会出现半透明遮罩，移动鼠标到目标位置
4. 左键点击获取坐标，右键/ESC 取消
5. 输入坐标描述（可选）
6. 坐标自动添加到列表

## 坐标拾取

- 点击「添加坐标 (抓取)」按钮
- 屏幕出现半透明遮罩
- 将鼠标移动到目标位置
- **左键点击**获取坐标
- **右键或 ESC**取消

## 基本设置

| 设置项 | 说明 |
|--------|------|
| 时间范围 | 只在指定时间段内执行点击 |
| 点击类型 | 左键单击/左键双击/右键单击/拖拽 |
| 执行间隔 | 每次点击之间的间隔时间 |
| 最大次数 | 点击次数上限（0=无限循环） |

## 系统托盘

- 点击窗口关闭按钮 → **最小化到托盘**（不退出）
- 托盘图标右键 → 显示主窗口 / 启用暂停 / 退出
- 开机自启可在「设置」Tab 中开启

## 配置文件

配置保存在 `.ClickScheduler.json`，坐标保存在其中：

```json
{
  "time_range": {"start": "08:00", "end": "22:00"},
  "click_type": "left_click",
  "interval": 30,
  "interval_unit": "minutes",
  "max_clicks": 0,
  "coordinates": [
    {"x": 100, "y": 200, "description": "点1"}
  ],
  "click_mode": "coordinate",
  "minimize_to_tray": true
}
```

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ClickScheduler main.py
```

生成的 exe 在 `dist/ClickScheduler.exe`

## 技术栈

- Python 3.x
- tkinter — GUI
- pyautogui — 鼠标点击模拟
- pystray — 系统托盘
- threading — 后台调度线程

## 注意事项

- 坐标基于**屏幕绝对位置**，分辨率变化后需要重新设置
- 运行时请勿移动鼠标到非目标区域
- 部分程序（如管理员权限窗口）可能需要本程序也以管理员身份运行
- 建议先测试坐标是否正确
